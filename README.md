# RetailDWH Bootcamp – DataBill

## 📌 Project Overview
This project is part of the DataBill Bootcamp, focusing on building a Retail Data Warehouse using SQL Server and SSIS.

## 🥉 Staging Layer
The current phase focuses on implementing the **Staging Layer** using a full-refresh approach.

### Key Features
- Created staging tables for Customers, Stores, Orders, Order Lines, and Product Catalog.
- Used SQL Server Integration Services (SSIS) to orchestrate the ETL workflow.
- Applied a full-refresh strategy by truncating staging tables before loading new data.
- Implemented stored procedures for staging table truncation and execution logging.
- Added execution tracking to monitor ETL operations and handle failures.

## 🛠️ Technologies
- Microsoft SQL Server
- T-SQL
- SQL Server Integration Services (SSIS)
- Visual Studio

## 🚧 Project Status
Currently working on the Staging Layer. More data warehouse components will be added as the project progresses.
